# Virtual Pharmacology Laboratory

Computer Assisted Learning for pharmacology practical teaching.

This public beta includes interactive animal model experiments for students and teachers. Anyone can download and use it for teaching and learning.

## Download

### Windows 10 and Windows 11

[Download the Windows application](https://github.com/ManuHCI/Computer-Assisted-Learning-/releases/download/v1.0.0-beta.1/Pharmacology_CAL_Public_Beta_v1.0.exe)

[SHA-256 checksum](https://github.com/ManuHCI/Computer-Assisted-Learning-/releases/download/v1.0.0-beta.1/Pharmacology_CAL_Public_Beta_v1.0_SHA256.txt)

Open the downloaded file. Windows may show a security message because the application is not digitally signed. Select **More info** and then **Run anyway**.

### Windows 7

[Download the Windows 7 legacy application](https://github.com/ManuHCI/Computer-Assisted-Learning-/releases/download/v1.0.0-beta.1/Pharmacology_CAL_Windows_7_Legacy_Beta_v1.0.exe)

[SHA-256 checksum](https://github.com/ManuHCI/Computer-Assisted-Learning-/releases/download/v1.0.0-beta.1/Pharmacology_CAL_Windows_7_Legacy_Beta_v1.0_SHA256.txt)

This best-effort legacy version is for 64-bit Windows 7 SP1 with the current servicing-stack and Universal C Runtime updates installed. Windows 7 is no longer supported by Microsoft or Python, so please test the application on the exact teaching computers before deployment and share feedback if you find any problem.

### Mac with Apple silicon

[Download the Mac application](https://github.com/ManuHCI/Computer-Assisted-Learning-/releases/download/v1.0.0-beta.1/Pharmacology_CAL_macOS_Public_Beta_v1.0.zip)

[SHA-256 checksum](https://github.com/ManuHCI/Computer-Assisted-Learning-/releases/download/v1.0.0-beta.1/Pharmacology_CAL_macOS_Public_Beta_v1.0_SHA256.txt)

This version is for Mac computers with an M series processor.

Unzip the file and open **Pharmacology CAL**. If macOS shows a security message, Control click the application, select **Open**, and confirm once.
